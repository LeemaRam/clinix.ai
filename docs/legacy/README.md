# Legacy Reference

This folder holds deprecated/reference material that is **not part of the active Clinix.ai runtime**.

## backend-legacy

The deprecated Flask backend (`backend-legacy/`) is **not present in this repository checkout**.
It is no longer part of the active runtime and is not referenced by `docker-compose.yml` or `start-local.ps1`.

If a `backend-legacy/` folder is ever reintroduced, it should be archived here and treated as reference only.

**Active backend is `backend-node/`. Do not start `backend-legacy`.**
